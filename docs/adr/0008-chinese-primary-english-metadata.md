# 中文为主，英文只到元信息层

站点只有中文正文，`<html lang>` 恒为 `zh-CN`，不生成任何 `/en` 路由。`titleEn` / `summaryEn` 两个字段只服务一件事：OG 卡片与分享预览——别人在 Twitter、微信里看到的是英文标题。

**Considered Options**：选择性英文全文（某篇文章写了英文版才生成 `/en/posts/<slug>/`）——需要 i18n 路由、语言切换控件、可选英文 RSS，并且每写一篇文章都要决定"这篇要不要英文版"，这个决定会反复出现；全站镜像——每篇两份正文，长期不可持续。

**Consequences**：国际读者读不到全文，只能看英文摘要后离开。`titleEn` / `summaryEn` 在**逐篇 OG 图落地之前不产生任何效果**（当前 OG 是单张静态 `public/og.png`），所以它们目前仍是不生效的字段，只是归属已经明确。将来若要做选择性全文，需要新增 `/en` 路由并接受"每篇都要做一次语言决定"的成本——这是天花板，不是计划。
